### ADAPT — good idea, wrong shape; take the core, change the mechanism

| # | Feature | Source | Our adaptation |
|---|---|---|---|

Free with capstone; charge institutions, not learners |
| B2 | **AI mentor / coach per learner** | ChatGPT, Gemini | Not in MVP (our locked decision: no LLM widget = no moderation surface, no minor exposure, no cost). | B3 | **AI Playground / sandbox** | ChatGPT, Gemini | The copy-button prompts in our station pages already are a guided playground. A free-form sandbox for Sprouts contradicts our curated-cards-only child safety rule. Adapt: add 2–3 alternate prompts per Try step instead |
| B4 | **Business Owners tier** (7th tier) | ChatGPT | Real audience in Thailand (SME owners aren't "office workers"), but a 7th line dilutes MVP. Adapt as an **Operators track** ("เจ้าของกิจการ SME") in phase 2 — same stations, different examples (marketing, ordering, customer replies) |
| B5 | **Learning-style dimension** (read/watch/do/listen) | ChatGPT | Don't add a 4th routing question — our stations already contain all modes (Watch video, read Try, do Make). Adapt: make the transcript/audio option more prominent instead |
| B6 | **Employer-sponsored badges → talent pool** | Gemini, ChatGPT, Kimi | We rejected placement/matching for licensing-risk reasons — that stands. | B7 | **Peer hubs / community forums** | Gemini, ChatGPT | Correct instinct, ruinous moderation cost — and a segregated kids' forum is a child-safety surface we refuse. Adapt: **facilitator community only** (teachers, librarians, HR) in LINE OpenChat, phase 3 |

| B9 | **"We're hiring" section** — Thai curriculum writers, part-time community managers, institutional partners, enterprise patrons | Kimi (TH About page) | Right idea, wrong timing: listing roles before launch signals scale that doesn't exist. | B10 | **Prompt Trainer** — learner writes a prompt, AI scores it on four stars (Clarity, Context, Format, Tone) and suggests improvements | ChatGPT (30-pg PDF, pp. 10–11, 19–20) | The best interactive-learning mechanic in any of the seven documents, but the LLM version breaks two locked decisions (no LLM widget in MVP; no free-text AI for minors). ## 4. What this changes in the build plan

**New pages (small, high leverage):** About/Founder story (Kimi's structure, condensed) · Operations AI Blueprints (Gemini's cards, PIC-sourced content) · Partner/Patron page with THB pricing (Kimi's table, validated numbers) — all three are static content, no new architecture.

**Phase plan additions:**
- Phase 0 (this week): + governance repo with decision log, risk register, and all existing deliverables as first commit (A8); + build-in-public cadence started (A9); + email/LINE signup and drop-off analytics on the existing prototypes so Phase 0 doubles as the demand test (A12) — line-level signup counts decide build order for lines 3–6
- Phase 1 (MVP): + About (using Kimi's TH structure and the "what Thai people believe they can do" thesis line), + "AI GPS" positioning in hero and patron deck (A11), + Blueprints, + Patron page with sponsorship ladder and the Corporate Patronage Deck as a real deliverable (A13, B9), + EdTech grant and developer-credit applications submitted (A13), + impact-loop copy. Case-study rewrite of 4 Operators steps using A10's explicit case→module index. + static four-part prompt self-check rubric under Operators/Builders Try steps (B10 stage 1)
- Phase 2: + SME-owner track inside Operators (B4), + Builders/Operators capstone certificates (B1), + "Second Career" module bridging Operators → Second Act (A10), + cross-line "related stations" links (B11)
- Phase 3: + white-label kit (A4), + facilitator community (B7), + Supabase/RLS when accounts arrive (B8), + scoped AI helper 20+ (B2), + AI-scored Prompt Trainer for Operators/Builders 20+ (B10 stage 2), + community-submitted blueprints behind a review gate (B12), + public hiring for writers/community roles once pilot report exists (B9)

**One naming note:** the candidates on the table are now **Pathwise AI** (Kimi — full brand pages already written), **AI Navigator** (Gemini — mockup and deck language exist), **AI Learning Compass** (ChatGPT — with the best argument: *"a roadmap is static; a compass helps people continuously navigate"*, which aligns exactly with our AI GPS framing in A11 and the transit-map architecture), and **AI Lines** (our working label). Naming gates the domain, the About page, the patron deck, and the GitHub organization — it is now the single decision blocking the most downstream work.

**One convergence worth recording:** ChatGPT's final chat independently prescribes the exact delivery sequence this project already followed — documents first, then wireframes, then plain HTML prototypes with no framework, then user testing, and only then the production build. Three of its five phases are already complete here. That is external validation of the build order, and it means the "10-week accelerator" ChatGPT proposes is, for this project, roughly a 4-week remainder.
